What this is

xentry runs a pinned CVE PoC inside a disposable target VM and, for remote PoCs, a separate attacker VM. It records runner facts and asks a separate model to assess them.

The verdict is an LLM assessment, not a deterministic proof and not a production risk assessment. The nonce value is never shown.

Link text and PoC text are sent to DeepSeek for extraction and validation. Do not submit client or sensitive material.
