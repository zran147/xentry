# Initial designs

The design and review documents this project was generated from, moved here
from the repository root where they sat among the code.

They are **history, not documentation.** They describe revisions 1 through 5 of
a design that has since been changed by four ADRs: the mirrors moved into their
own VM, the model gained the ability to provision a target, and the host-side
package services were deleted outright. Where one of these files disagrees with
`docs/designs/xentry-v1-contracts.md`, the ADRs, or the code, it is wrong and
the code is right.

They are kept because they record *why* the early decisions were made, and
because the review reports name failures that shaped the current design. Start
from [`../../../README.md`](../../../README.md) and
[`../SITEMAP.md`](../SITEMAP.md) instead.
